# Sol Nascente — Brazil, from first light

Private journeys across Brazil. Next.js 16 (App Router), TypeScript, Tailwind CSS 4, Framer Motion, Lenis.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
npm run lint
```

## Where things live

| What | Where |
| --- | --- |
| Brand colours, fonts, promise | `config/brand.ts` (+ CSS tokens in `app/globals.css`) |
| Contact, Cadastur, anchor menu, page links | `config/site.ts` |
| Carnival & festival dates (**verify yearly**) | `config/carnival.ts` |
| Currency rates (placeholder) | `config/currency.ts` |
| All content (typed) | `data/*.ts` — types in `lib/types.ts` |
| Photo/video manifest + credits | `data/media.json` (keys used via `img()` / `video()` in `lib/media.ts`) |
| Self-hosted background videos | `public/media/video/` — add one with `scripts/encode-video.sh <file> <name> [start] [seconds]`, then `node scripts/set-video.mjs <key> <name>` |
| Journal posts (MDX) | `content/journal/*.mdx`, registered in `content/journal/index.ts` |
| Enquiry API (logs payload, CRM TODO) | `app/api/enquiry/route.ts`, schema in `lib/enquiry.ts` |
| Brazil map + biome shapes | generated by `node scripts/build-map.mjs` → `data/brazil-map.json` |

Homepage sections are in `components/home/`, interactive features (biome explorer, Carnival quiz, water toggle, sunrise coast) in `components/features/`.

## Before launch

- **Placeholders**: stay names, team, reviews, portrait quote, company name/address/Cadastur, booking terms and privacy text. All are flagged in the UI.
- **Verify** (marked with a "verify" badge on the site): visas, health advice, Noronha fees, Carnival/Festa Junina/Parintins dates, water seasons and best months, Lençóis lagoon season.
- **Media**: placeholder Unsplash/Pexels media (credited at `/legal#credits`). Videos are self-hosted (720p desktop / 540p mobile) via `scripts/encode-video.sh`. The "A Day in the Pantanal" clips are Brazil footage but not confirmed Pantanal locations: no free, verifiable Pantanal video was found. Replace with your own footage.
- **Currency** rates in `config/currency.ts` are indicative placeholders.
- Set `NEXT_PUBLIC_SITE_URL` for canonical URLs, sitemap and Open Graph.

## Internationalisation

English only for now. All copy sits in typed data files and `config`, not in components, so adding Portuguese means adding translated data (e.g. `data/pt/…`), adding `"pt"` to `site.locales`, and moving routes under an `app/[locale]` segment.

## Notes

- Motion respects `prefers-reduced-motion`: no autoplaying video, no marquee, no pinned scroll scenes.
- Background videos load only near the viewport (the hero waits until the page has loaded), phones get a lighter file, save-data visitors get posters only, and every video has a pause control and a caption track.
- framer-motion runs through `LazyMotion`, so animation features load after first paint.
- Biome boundaries on the map are simplified approximations (after IBGE); the outline is Natural Earth (public domain).
