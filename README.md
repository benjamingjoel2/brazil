# Sol Nascente — Brazil, from first light

Private journeys across Brazil. Next.js 16 (App Router), TypeScript, Tailwind CSS 4, Framer Motion, Lenis.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
npm run lint
```

## Where things live

| What | Where |
| --- | --- |
| Brand colours, fonts, promise | `config/brand.ts` (+ CSS tokens in `app/globals.css`) |
| Contact, Cadastur, anchor menu, page links | `config/site.ts` |
| Carnival & festival dates (**verify yearly**) | `config/carnival.ts` |
| Currency rates (placeholder) | `config/currency.ts` |
| All content (typed) | `data/*.ts` — types in `lib/types.ts` |
| Photo/video manifest + credits | `data/media.json` (keys used via `img()` / `video()` in `lib/media.ts`) |
| Self-hosted background videos | `public/media/video/` — add one with `scripts/encode-video.sh <file> <name> [start] [seconds]` (or `scripts/photo-to-loop.sh <photo> <name> [zoom\|pan-right\|pan-left]` for an animated still), then `node scripts/set-video.mjs <key> <name>` |
| Journal posts (MDX) | `content/journal/*.mdx`, registered in `content/journal/index.ts` |
| Enquiry API (logs payload, CRM TODO) | `app/api/enquiry/route.ts`, schema in `lib/enquiry.ts` |
| Brazil map + biome shapes | generated by `node scripts/build-map.mjs` → `data/brazil-map.json` |

Homepage sections are in `components/home/`, interactive features (biome explorer, Carnival quiz, water toggle, sunrise coast) in `components/features/`.

## Languages

English (default) at the current URLs; French, German and Spanish under `/fr/`, `/de/` and `/es/`. Every page is pre-rendered in all four; no translation code ships to the browser.

| What | Where |
| --- | --- |
| English source routes | `app/(en)/` (route group, its own root layout with `<html lang>`) |
| Generated locales | `app/fr`, `app/de`, `app/es` and `.i18n/<locale>/` (git-ignored), written by `scripts/i18n-build.mjs` before `dev` and `build` |
| Translations (English string → translation) | `i18n/fr.json`, `i18n/de.json`, `i18n/es.json` |
| Translated journal posts | `i18n/content/<locale>/journal/*.mdx` |
| Translated video captions | `public/captions/<locale>/*.vtt` |
| Locale constants (`locale`, `homePath`, Intl/OG locale) | `lib/locale.ts` (rewritten per locale by `scripts/i18n.config.mjs`) |
| Language selector (EN · FR · DE · ES) | `components/layout/LanguageSwitcher.tsx`, in the header (tablet and up) and the menu panel |
| hreflang, canonical, sitemap | `languageAlternates()` in `lib/seo.tsx`, `app/sitemap.ts` |
| Unmatched URLs | `app/global-not-found.tsx` |

When you change English copy: `npm run i18n:extract` refreshes `i18n/strings.json`, `npm run i18n:missing -- --list` shows what has no translation yet (place names and Portuguese terms are left as they are on purpose), then add the translations to the three JSON files. Values that act as identifiers (region and stay-type keys, enquiry option values) keep English keys with translated labels (`regionLabel`, `stayTypeLabel`); the enquiry API validates against the visitor's language (`app/api/enquiry/route.ts`) and records `locale` with each enquiry.

## Notes

- Motion respects `prefers-reduced-motion`: no autoplaying video, no marquee, no pinned scroll scenes.
- Background videos load only near the viewport (the hero waits until the page has loaded), phones get a lighter file, save-data visitors get posters only, and every video has a pause control and a caption track.
- framer-motion runs through `LazyMotion`, so animation features load after first paint.
- Biome boundaries on the map are simplified approximations (after IBGE); the outline is Natural Earth (public domain).
